Regime-Favored Assets
Ranks assets by their historical 3-month forward return in the current regime. Each past month is matched to today by macro conditions (7yr growth = SPX − Oil, inflation = Gold − 10Y UST TR) and by Vanda positioning, then we measure the 3-month forward return. 3M Return = the weighted-average 3-month forward return across those matched months. Win% = how often that return was positive. Fully deterministic — no models or randomness.
